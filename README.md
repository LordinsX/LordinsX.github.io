# AIRSOFT OPS — сайт анонсов страйкбольных игр

Полностью статический сайт (один файл `docs/index.html`), рассчитан на **GitHub Pages**:
`https://<логин>.github.io/<репозиторий>/`

## Что на сайте

- **Лента анонсов игр** — карточки со статусами «Набор открыт / Заполнено / Завершена»,
  подсветкой игр ближайшей недели, взводом, прогрессом состава и кнопкой «Записаться».
- **Поиск и фильтры** (предстоящие / все / прошедшие), добавление и удаление анонсов.
- **Обратный отсчёт** до ближайшей игры и живая статистика (игр в планах, свободных мест).
- **Календарь игр** на месяц с переходом к анонсу по клику на дату.
- Секции **«О проекте»** и **«Запись и связь»** (контакты координатора, регламент, новичкам).

## Публикация на GitHub Pages

1. Запушьте репозиторий на GitHub:
   ```bash
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```
2. CI настроен: `.github/workflows/pages.yml` при каждом пуше в `main` публикует папку `docs/`
   (GitHub Pages → Source: **GitHub Actions**). Альтернатива без Actions:
   Settings → Pages → Source: *Deploy from a branch* → `main` / `/docs`.
3. Сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Редактировать контент — просто правьте `docs/index.html` и пушьте. Никакого Node.js не требуется.

## Хранение данных

- По умолчанию анонсы синхронизируются через **Firebase Realtime Database**
  (REST-запросы к узлу `/airsoft_games`) — список общий для всех игроков,
  обновления подтягиваются каждые 30 секунд. В шапке статус `// ОНЛАЙН-СИНХРО`.
- Если база недоступна/закрыта правилами, сайт работает автономно:
  данные в `localStorage` браузера + демо-анонсы при первом запуске (`// ЛОКАЛЬНЫЙ РЕЖИМ`).

### Чтобы включить общую синхронизацию

В консоли Firebase → Realtime Database → Rules:

```json
{
  "rules": {
    "airsoft_games": { ".read": true, ".write": true },
    ".read": false,
    ".write": false
  }
}
```

Адрес базы задаётся в начале `<script>` в `docs/index.html`:
`const FIREBASE_URL = 'https://lordinsxtest-default-rtdb.europe-west1.firebasedatabase.app';`
